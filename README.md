# K-Delta — Indian Equity Market Intelligence

Real-time Indian stock market analytics, candlestick pattern recognition, multi-indicator confluence scoring, and volatility-adjusted execution targets for NSE & BSE securities.

---

## 🚀 Features

- **Real-Time Candlestick Charts**: Powered by TradingView Lightweight Charts with multi-timeframe auto-scaling (`1m`, `3m`, `5m`, `15m`, `30m`, `1h`, `1D`, `1W`).
- **Technical Analysis Inspector**: Dynamic confluence scoring, candlestick pattern signals, and trade execution targets (Entry, Stop Loss, Target 1, Target 2).
- **Persistent Watchlist**: Track favourite Indian equities with real-time price updates and quick symbol navigation.
- **Dark Theme Interface**: High-contrast, responsive UI tailored for day traders and market analysts.
- **Secure Authentication**: Express & JWT backend authentication with session security.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Dark & Violet Aesthetic), JavaScript (ES6+)
- **Charts**: TradingView Lightweight Charts
- **Backend**: Node.js, Express, WebSockets (`ws`), Yahoo Finance API
- **Authentication**: JWT, bcryptjs

---

## ⚡ Quick Start

1. **Clone Repository**
   ```bash
   git clone https://github.com/specter-358/K-Delta.git
   cd K-Delta
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Server**
   ```bash
   npm start
   ```
   Open `http://localhost:3000` in your browser.
